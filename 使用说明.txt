EasyRecorder 录屏工具 · 新手使用说明
========================================

【第 1 步】把这个文件夹放到电脑上
----------------------------------------
建议放到 D 盘，例如：
    D:\EasyRecorder\

文件夹里应该有这两个文件：
    EasyRecorder.exe
    使用说明.txt（本文件）


【第 2 步】双击运行
----------------------------------------
双击 EasyRecorder.exe。

如果 Windows 弹出蓝色的“已保护你的电脑”提示：
    点击“更多信息” → 点击“仍要运行”。
这是因为程序没有购买数字签名证书，属于正常现象。

打开后，屏幕顶部会出现一条深色工具栏：
    区域 | 录制 | 暂停 | 结束 | 取消 | 选项 | 状态 | 计时 | 关闭


【第 3 步】开始录屏
----------------------------------------
1）想录全屏：直接点“录制”。
2）想录一部分：先点“区域”，按住鼠标左键拖动框选，松开即完成选择。
3）录制中：
   - 点“暂停”暂停，按钮会变成“继续”，再点一次接着录。
   - 点“结束”保存文件。
   - 点“取消”放弃这次录制，不保存（会先问一次）。
4）保存位置：
   默认在“视频”文件夹里的 EasyRecorder 文件夹。
   想改位置：点“选项” → “文件保存位置” → 浏览。
5）声音设置：
   点“选项”，可以选：
   - 录制系统声音（电脑里播放的声音）
   - 录制麦克风声音（你说话的声音）
   - 同时录制系统声音和麦克风
   - 不录声音
   默认是“同时录制系统声音和麦克风”。


【输出格式】
----------------------------------------
- 视频：MP4（H.264）
- 声音：AAC，48 kHz 立体声
- 系统声音和麦克风同时录制时，程序会自动把两路声音混合好，不需要你设置任何参数。


【常见问题】
----------------------------------------
1. 提示缺少 Visual C++ 运行库
   请安装 Microsoft Visual C++ Redistributable（x64）：
   https://aka.ms/vs/17/release/vc_redist.x64.exe

2. 录出来没有声音
   打开“选项”，确认声音来源没选成“不录声音”。
   如果只录麦克风，请到 Windows 设置 → 隐私和安全性 → 麦克风，
   确认“允许桌面应用访问麦克风”是打开的。

3. 工具栏挡住画面
   工具栏已经设置为“录制时不出现在录像里”（Windows 10 2004 及以上支持）。
   如果仍出现在录像中，可以拖动工具栏到不挡画面的位置，或先用“区域”避开它。

4. 想直接退出
   点“关闭”。如果正在录制，程序会先问你是否结束并保存。

5. Windows N / KN 版无法录制
   请先安装对应系统的媒体功能包（Media Feature Pack）。

6. 提示缺少 .NET，或双击后没有反应
   请安装 .NET 8 Desktop Runtime（x64）：
   https://dotnet.microsoft.com/en-us/download/dotnet/8.0


【系统要求】
----------------------------------------
- Windows 10 / Windows 11（64 位）
- 需要已安装 .NET 8 Desktop Runtime（x64）：
  https://dotnet.microsoft.com/en-us/download/dotnet/8.0
- 无需安装 FFmpeg
- 需要 Microsoft Visual C++ Redistributable（x64）
